# 📚 Curso Udemy: JavaScript e TypeScript do Básico ao Avançado (com Projetos)

Este repositório serve como um espaço para organizar e documentar os **exercícios, projetos e anotações** desenvolvidos durante o curso [**"JavaScript e TypeScript do Básico ao Avançado (com Projetos)"**](https://www.udemy.com/), da Udemy.

---

## 🎯 Objetivo do Repositório

Os principais objetivos são:

- **Centralizar o progresso:** Manter um registro organizado de todo o material prático do curso.  
- **Facilitar revisão e consulta:** Servir como recurso rápido para revisar conceitos e soluções.  
- **Compartilhar aprendizado:** Disponibilizar as soluções e anotações para outros estudantes e interessados.  

---

## 🚀 Tecnologias Abordadas

O curso (e este repositório) cobre conceitos e práticas envolvendo:

- **JavaScript (ES6+):** Fundamentos, manipulação do DOM, assincronismo, POO e boas práticas.  
- **TypeScript:** Tipagem estática, interfaces, classes e como aprimorar projetos JavaScript.  
- **Node.js:** Introdução ao uso de JavaScript/TypeScript no backend.  
- **HTML & CSS:** Para construção dos projetos front-end desenvolvidos ao longo do curso.  

---

## 📂 Estrutura do Repositório

A estrutura reflete a organização do curso, facilitando a navegação pelos arquivos:

```
.
├── section-01/
│   ├── exercicio-1.js
│   └── notas.md
├── section-02/
│   ├── projeto-x/
│   └── ...
└── ...
```

- **`section-XX/`**: Cada pasta corresponde a uma seção do curso.  
- **`exercicio-X.js` / `projeto-X/`**: Exercícios ou projetos da seção.  
- **`notas.md`**: Anotações pessoais sobre os tópicos abordados.
